# EcoCredit Exchange ♻️

A complete, zero-dependency decentralized web platform connecting scrap recyclers and corporate buyers for verified Extended Producer Responsibility (EPR) e-credits.

---

## 🌟 Key Features

- **Role-Based Portals**:
  - **Seller Mode (Scrappers / Recyclers)**: List e-waste, lithium batteries, and scrap credits immediately or schedule them for future automated market launch; manage yard inventory; track corporate payouts.
  - **Buyer Mode (Corporate Entities)**: Full-width live exchange to browse available credits, execute buyouts, and automatically generate verifiable EPR compliance certificates.
- **Doorstep Scrap Logistics (🚚 Tab)**: Schedule transport vehicles (from 500 kg mini-vans up to 10-ton multi-axle haulers) with live payload estimation and dispatch IDs.
- **Third-Party Lab Quality Auditing (🔬 Tab)**: Submit lots for ISO-accredited purity assay testing with tamper-proof certificates.
- **EPR Proof Certificates (📜 Tab)**: Official regulatory-ready certificates complete with SHA-256 cryptographic offset hashes.
- **Help Desk & Mediation (🤝 Tab)**: Dispute resolution and direct mediation request ticketing.
- **Personal EcoAI Assistant (🤖)**: Real-time contextual advisor for scrap market rates, battery packaging regulations, and CPCB compliance quotas.

---

## 🚀 How to Run Locally

1. Simply double-click `index.html` in your file explorer.
2. It will open instantly in your default web browser (Chrome, Edge, Safari, Firefox).
3. **No installation required**: No Node.js, Python server, or database setup needed!

---

## 🌐 How to Publish & Deploy (Free & Instant)

### Option 1: GitHub Pages (Recommended)
1. Go to [GitHub](https://www.google.com/search?q=https%3A%2F%2Fgithub.com) and create a new repository (e.g., `ecocredit-exchange`).
2. Upload `index.html` and `README.md` to the repository.
3. In your repository, click **Settings** > **Pages** (in the left sidebar).
4. Under **Build and deployment > Branch**, select `main` (or `master`) and folder `/(root)`, then click **Save**.
5. Your app will be live worldwide in ~1 minute at:
   `https://<your-github-username>.github.io/ecocredit-exchange/`

### Option 2: Netlify (Drag & Drop)
1. Go to [app.netlify.com/drop](https://www.google.com/search?q=https%3A%2F%2Fapp.netlify.com%2Fdrop).
2. Drag and drop the folder containing `index.html`.
3. Your app is immediately deployed on a free global URL!

### Option 3: Vercel
1. Import your GitHub repository on [vercel.com](https://www.google.com/search?q=https%3A%2F%2Fvercel.com).
2. Click **Deploy** (zero configuration needed).
